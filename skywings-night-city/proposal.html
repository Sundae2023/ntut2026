專案背景與動機

近年來，視覺設計圈吹起了一股強烈的復古未來主義（Retro-futurism）與賽博龐克（Cyberpunk）熱潮。

從街頭潮牌、音樂專輯視覺，到各大品牌的商業設計，我們觀察到「高對比、螢光色、錯位、雜訊與科技感」的酸性設計（Acid Graphics）正大量回歸。這種風格打破了過去企業追求的「乾淨、明亮、平滑」的美學標準，轉而擁抱衝突與迷幻感。

因此，我們決定以「雲端旅行社」為概念，將傳統的航空旅遊網站，重新包裝成一個帶有強烈賽博龐克風格的「塔台廣播站」。我們希望透過螢光綠、掃描線、等寬字體與硬邊陰影，重塑飛行前那種充滿未知與科技感的期待，證明旅遊網站也能擁有極具個性的視覺衝擊力。

// SYSTEM LOG: 02

痛點與需求 // ERROR REPORT

01

視覺同質性過高

目前的旅遊網站大多採用千篇一律的藍天白雲、圓角卡片與柔和色調，缺乏獨特的品牌個性與視覺記憶點。

02

缺乏動態樂趣

使用者只能被動瀏覽靜態資訊，所有按鈕點擊後都只會跳出制式的訂票表單，缺乏引人探索的互動體驗。

03

無情感連結

冷冰冰的制式訂票流程，無法傳遞旅行應有的期待感。缺乏一個「世界觀」讓使用者產生沉浸感。

// SYSTEM LOG: 03

解決方案 // PATCH NOTES

A

建立強烈世界觀與文案

將網站化身為「雲端旅行社」。導覽列是「頻道」，預訂按鈕是「領取登機證」，彈出通知是「塔台廣播」，讓使用者沉浸在故事中。

B

酸性視覺衝擊

大膽採用黑色背景，搭配螢光綠（#39ff14）、電光紫與賽博粉。全站使用無襯線與等寬字體，並加入掃描線（Scanlines）與硬邊陰影（Hard Shadow）特效。

C

動態互動體驗（活的網頁）

加入「目的地轉盤」讓使用者隨機抽籤，頁尾加入「即時塔台時鐘」每秒跳動，讓網頁不再死氣沉沉，而是隨時在運作。
